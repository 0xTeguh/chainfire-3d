CHAINFIRE is a 3D tower defense game (Three.js/WebGL): draw powder trails, light the fuse, and chain explosions through 10 waves to burn the Cinder Titan. Defend the fort with 4 defenders (Wren, Pip, Old Thom, Mira) against 4 raiders, draft cards between waves, and build barrel chains for massive chain reactions.

## Run it

```sh
node --experimental-strip-types serve.ts
```

Then open http://localhost:8081/game/ in your browser.
